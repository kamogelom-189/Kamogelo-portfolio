# Kamogelo Portfolio

A personal portfolio website for Kamogelo Mathe, a second-year Software Development student focused on building practical web and software solutions. The site presents an overview of skills, selected projects, and ways to get in touch.

## Overview

This project is a static portfolio landing page built with HTML, CSS, and JavaScript. It highlights:

- Personal branding and profile introduction
- Skills and learning focus
- Selected student projects
- Contact links for GitHub, email, and LinkedIn
- Responsive layout for desktop and mobile devices

## Live / Local Preview

The portfolio is a front-end static website with no build step required.

### Option 1: Open directly
- Open `kamogelo-portfolio-updated/kamogelo-portfolio-updated/index.html` in a browser.

### Option 2: Use a local web server
```bash
cd kamogelo-portfolio-updated/kamogelo-portfolio-updated
python3 -m http.server 8000
```

Then visit:
```text
http://localhost:8000
```

## Customization

If you want to personalize the portfolio:

1. Update the content in `index.html` with your own bio, skills, and project details.
2. Replace or update files in the `images/` folder to match your projects.
3. Modify colors, typography, and layout in `style.css`.
4. Adjust interactions and dynamic behavior in `script.js`.

### Profile photo

The README notes that the site expects a profile image named `profile.jpg` in the same folder as the page if you want to replace the placeholder. If you use a different file name, update the `src` attribute in `index.html`.
